# Ilustrácie (rytiny ovocia z etikiet)

- Ideálne zdrojové súbory od grafika: **AI / PSD / SVG**, alebo **PNG s priehľadným pozadím** vo vysokom rozlíšení (min. 2000 px na šírku).
- **Bez pečiatok a bez textu** – pečiatky („Za studena lisované“, „Zo slovenských sadov a polí“) prosím ako samostatné súbory.
- Pomenovanie podľa produktu: `jablko-ribezla`, `cvikla`, `paradajka`, `mrkvicka`, `broskyna`, `dulienka`, `aronilka`, `drienocka`, `marhulienka`.
