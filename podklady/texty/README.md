# Texty

Stačí Word alebo obyčajný text. Ideálne:

- Úvodný slogan + 2–3 vety pod ním
- O značke / o spoločnosti (krátko)
- Ako objednávať (môžem navrhnúť sám)
- Kontakt na obchodné oddelenie (meno, email, telefón) – zobrazí sa tým, čo ešte nie sú klientmi
- Fakturačné údaje AQUA PRO EUROPE, a.s. do pätičky (IČO, DIČ, sídlo, zápis v registri)
