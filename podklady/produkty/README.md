# Produkty (9 štiav)

**Fotky:** jedna hlavná fotka na produkt, ideálne na bielom alebo priehľadnom pozadí,
min. 1500 px na šírku. Pomenuj súbor podľa produktu, napr. `jablko.png`, `pomaranc.jpg`.

**Zoznam produktov** – nahraj sem súbor `produkty.xlsx` (alebo .csv / .docx) so stĺpcami:

| Stĺpec | Príklad | Povinné |
|---|---|---|
| Interný kód (SKU / EAN) – rovnaký ako vo vašom systéme | AQ-JAB-1L | áno |
| Názov | Jablkový džús 100 % | áno |
| Objem / balenie | 1 l, sklo | áno |
| Krátky popis (1–2 vety) | Lisovaný z… | áno |
| Zloženie | 100 % jablková šťava | nie |
| Alergény / poznámky | – | nie |
| Názov súboru s fotkou | jablko.png | áno |

Poznámka: objednáva sa po kusoch, vždy v násobkoch 12 (celá prepravka, môže byť mix).
