# Vita Pro – objednávkový systém

B2B objednávkový web pre klientov AQUA PRO EUROPE, a.s. (bez cien).

## Podklady

Všetky podklady nahrávaj do priečinka [`podklady/`](podklady/) cez GitHub:
**otvor priečinok → Add file → Upload files → Commit changes**.

| Priečinok | Čo tam patrí |
|---|---|
| `podklady/logo/` | Logá (ideálne SVG, alebo PNG s priehľadným pozadím) |
| `podklady/produkty/` | Fotky jednotlivých štiav + zoznam produktov |
| `podklady/fotky/` | Atmosférické / úvodné fotky (ovocie, výroba, ľudia…) |
| `podklady/texty/` | Texty na web (úvod, o nás, kontakt obchodného oddelenia) |
| `podklady/pravne/` | VOP, GDPR, cookies |

Každý priečinok má vlastný `README.md` s podrobnosťami.
